# 午夜时分

钢琴练习伴侣。手机放在琴谱架上，听孩子弹琴，画面跟着弹到的小节和力度变化：半夜醒来的小男孩走过月光下的走廊，心跳变快，影子变大，原来是自己的影子，最后钻回被窝。

一个单文件网页应用，没有后端，所有声音分析都在手机上进行，不上传任何录音。

## 使用

1. 打开 `index.html`，必须是 **https** 网址，手机浏览器才允许使用麦克风。
   最省事的办法是 GitHub Pages：仓库 Settings → Pages → Deploy from a branch → `main` / root。
2. 点“乐谱设置”，一个小节一行，点选一行后用按键填音（每小节 4 拍，长音标拍数，没有声音的拍点“休止”）。拍数不对的小节会变橙色。也可以在“更多”里粘贴整段，自动拆成小节。乐谱只保存在这台手机的浏览器里，保存一次就不用再输入。要换手机，在乐谱设置里点“复制乐谱链接”，在另一台手机打开该链接即自动导入。
3. 点“开始演奏”，允许麦克风，先安静一秒，然后开始弹。
4. 想练音量：让老师认可的大声版本先弹一遍，点“记录标准音量”。之后练习时音量条会显示每一段的目标线，不够响会提示“再大一点”。手机每次要放在同一个位置。
5. “听示范（按乐谱出声音）”：用你输入的乐谱合成钢琴声并同步画面（速度 ♩=80）。乐谱只有音名没有高低八度，所以每个音取离上一个音最近的八度，只有右手旋律，没有左手。
6. 没有乐谱时也能用，画面按时间往前走，可以用 ◀ ▶ 手动对到小节。“看一遍画面”不需要麦克风。

## 乐谱格式

```
音名 空格 分隔，小节用 | 分隔
升号 #，降号 b（写在大写音名后，如 Bb）
:拍数 表示这个音的拍数，不写是 1 拍，如 G:3
休止写 0 或 R，同样可以加 :拍数，如 0:1
```

## 目录

- `index.html`：构建好的完整应用，直接部署这个文件。
- `src/tracker.js`：乐谱解析、音头检测、音高检测、跟谱。
- `src/scene.js`：走廊动画（Canvas）。
- `src/app.src.html`：界面和麦克风、音量逻辑。
- `src/build.py`：把上面三个文件合成 `index.html`。
- `src/test.js`：用模拟数据测试跟谱和音头、音高检测，运行 `node src/test.js`。

## 构建与测试

```
python3 src/build.py
node src/test.js
```
